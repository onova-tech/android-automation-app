# Specs Directory

This directory contains implementation specifications following the spec-driven workflow. Specs are created for each implementation task based on Linear tickets and follow the mandatory template format with testable acceptance criteria, pattern references, and success validation commands.

## Pattern Library

Pattern files referenced by specs:

- **Research**: `patterns_library/research/` - Technical analysis patterns
- **Evaluation**: `patterns_library/evaluation/` - Tool comparison patterns  
- **Architectural**: `patterns_library/architectural/` - Feasibility study patterns

## Workflow

1. Create spec based on Linear ticket description
2. Add pattern references to existing patterns or create new ones
3. Define testable acceptance criteria
4. Provide success validation commands
5. Add demo script for verification
6. Create logical commits following SAFe format
